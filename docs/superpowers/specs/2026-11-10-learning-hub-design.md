# 小芽学习乐园设计

将数字启蒙扩展为数字、拼音、英文字母三个独立学习空间，首页只呈现学习入口、继续学习与精选游戏，解决功能增加后入口堆积的问题。

- 数字：保留 1–10 卡片、描画、儿歌与全部九个原有游戏。
- 拼音：依照 2024 新版人教版一年级上册编排核对课次，提供课程卡片、声调与例字提示，新增听辨、分类、声调三个游戏。教材顺序有来源记录，界面不使用教材原图或宣称官方产品。语音必须清楚区分例字参考与拼音音素。
- 英语：A–Z 大小写、字母名和基础单词点读，新增大小写配对、听辨、顺序三个游戏。
- 排版：桌面侧栏与移动底栏共用导航；首页、数字、拼音、英语、游戏大厅各为独立视图，使用 URL hash 支持返回和直达。游戏大厅按学科筛选。
- 视觉：奶油色背景、绿色主色、紫色拼音、橙色英语；大号内容和触摸按钮，控制首页信息量，支持窄屏与减少动态效果偏好。
- 进度：保留 number-garden 的旧数字进度；新增学习记录独立存储，校验数据并容忍 localStorage 不可用；成就覆盖三个学科。
- 技术：原生 JS/CSS/SVG、Vite，复用统一 dialog、音效、奖励。英语显式使用 en-US，关闭声音和关闭弹窗会停止活动。
- 验证：Node 内建测试覆盖课程范围、题目答案/边界和存储兼容性；生产构建；浏览器检查三科课程、新旧游戏、奖励、静音、导航与移动布局。
