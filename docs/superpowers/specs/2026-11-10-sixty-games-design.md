# 每科20个小游戏

数字、拼音、英文字母各20个，总计60个；保留既有9/3/3个，分别增加11/17/17个。每个新游戏有独立学习目标，每次5关，无计时、答错可重试，通关才累计一次奖励。拼音课程保持2024新版人教教材14课顺序，游戏使用自主设计练习，合成语音仅用于例字参考。

选择共享的轻量活动播放器：选择题、依次组装、多选分类、增减装填。三科各自负责纯题库及生成器，独立测试题目正确性。保留原有特殊玩法的画布、翻牌、气球和音效。相较每个游戏复制DOM流程，共享播放器统一了键盘、静音、重开、关闭和防重复奖励；各科题目仍可独立演进。

游戏目录为单一来源，保存学科、键值、标题、说明、图标、目标、分类。首页计数、各科20个入口、游戏大厅全部由目录生成。大厅按学科、练习目标筛选并支持标题/描述搜索；各科页按四种目标分组，避免无分组长列表。所有入口均可用原生按钮操作，手机无横向溢出。

验证：题目答案可达且不重复、随机边界、数学及拼音/字母规则、生命周期及目录覆盖；浏览器检查全部入口及各交互完整5关、重试/重开/静音/关闭与移动布局；生产构建、Docker健康及HTTPS代理。修改先在本机完成，再按已授权流程提交推送main并更新远端Docker。
