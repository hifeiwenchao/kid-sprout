# 萌芽启蒙原生客户端：第一阶段

## 目标

用 SwiftUI 与 Jetpack Compose 分别实现可运行、离线可用的 iPhone/iPad 和 Android 手机/平板应用，不使用 WebView。第一阶段交付数字学习、三种游戏、画板和本地进度；拼音、字母和其余游戏在后续阶段迁移，当前界面不展示未实现的入口。

## 产品行为

- 品牌为“萌芽启蒙”，免费、无账号、无广告、无打赏。主导航为探索、数字乐园、小游戏、画板和家长区，按屏幕宽度采用侧栏或底部导航。
- 数字课程覆盖 0–10，可选择任意数字、点读、逐个点水果、标记学过和继续学习。任意顺序点水果时播报已点过的不同水果数量，重复点击不重复累计。0 用空篮子与放入/取出苹果理解。
- 游戏为数一数水果、寻找数字、比比多少，每局五关。答错可重试，答对锁定本关，显式下一关；第五关结束只奖励一次，课程进度与游戏奖励分开保存。
- 画板支持触摸（iOS 同时支持 Apple Pencil）、颜色、粗细、橡皮擦、撤销、重做、清空、自动保存草稿和 PNG 系统分享。纸面使用归一化坐标或固定逻辑尺寸，旋转与窗口变化不能挤坏或丢失笔迹。
- 本地记录使用各平台的持久化文件或系统偏好保存；重启能恢复，损坏数据安全回退。网页存档与客户端独立。
- 中文合成语音使用系统服务，可关闭；未安装离线中文语音时仍可通过文字与图形学习。
- 家长区包含作者介绍及 `hi@feiwenchao.com` 邮件链接；系统分享、邮件等外部入口经过简单家长算术验证。儿童区可独立使用，不要求提供个人信息。
- 控件有文字/辅助功能标签，触控区域至少 iOS 44pt / Android 48dp；支持深浅系统设置下的文字对比及减少动画偏好（首版可使用静态界面）。

## 技术边界

- iOS 最低 iOS 17，SwiftUI + PencilKit + AVFoundation；bundle ID `com.feiwenchao.kidsprout`，不引入第三方运行依赖。
- Android 最低 API 26，Kotlin + Jetpack Compose + Android TextToSpeech；application ID `com.feiwenchao.kidsprout`，不申请 INTERNET、存储、相机或麦克风权限。
- 共享内容由 `native/shared/curriculum.json` 提供，`schemaVersion` 为 1；根字段 `brand`, `numbers`, `pinyin`, `alphabet`。numbers 为 `{value: Int, name: String}` 数组，数字唯一且顺序为 0–10。两端将同一文件打包进离线资源。
- 不替换网页实现，不自动发布商店。提供可验证的模拟器构建与 Android debug APK；发布签名与商店素材另行配置。

## 验收

网页原有测试与生产构建通过；共享内容与网页课程一致；两端游戏状态机、持久化校验有单元测试；iOS 模拟器构建/运行及 Android debug APK 构建通过；手机/平板布局和核心交互完成检查。
