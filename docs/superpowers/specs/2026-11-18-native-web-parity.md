# 全端原生与网页版一致

用户已选择完整复刻网页版，并明确包括所有原生端：iPhone、iPad、Mac、Android手机与平板。以当前网页源码为设计、内容与玩法基准，全部使用SwiftUI/AppKit/PencilKit或Jetpack Compose/Canvas，不在客户端执行网页JavaScript或使用WebView。应用免费、离线、无账号/广告/内购。

页面包括探索首页、数字乐园、拼音天地、字母森林、小小画板、游戏大厅，以及独立的家长说明/作者介绍。统一奶油白、鼠尾草绿、浅紫、淡金配色，细描边与圆角卡片、原有SVG插画、导航名称、页面标题/文案层级。Mac/iPad/Android平板使用完整学习地图侧栏，窄屏保留全部六入口，避免系统TabView自动把后续入口隐藏进More。适配深浅外观、动态字号和减少动画。

完整课程为0–10数字、2024新版人教顺序14课拼音/47声韵母/16整体认读/四声、26对字母与四个分组。数字卡使用网页对应物体，零为空篮子互动；拼音展示口型/例字/规则/拼读，注明合成语音仅为例字读音参考；字母名和单词分别使用英语。课程详情有记忆小剧场（有限播放、可重播、减少动画时静态）及数字/大小写临摹。课程完成、游戏奖励分别统计，兼容已有本地记录。

游戏目录与网页相同，三个学科各20款，支持学科/目标/关键词交集筛选及空状态。45个新增游戏采用原题库导出的选择、顺序、多选、装填玩法；15个原有游戏保留原始玩法与关数，尤其数字翻牌3关、气球3关、描画自由练习，其余五关。火车、胡萝卜比较、点心装填、听鼓使用对应场景，不能把不同玩法全部退化成答题卡。答错可重试，答对锁定，末关显式完成且奖励只领取一次。

构建时由网页纯数据/出题函数生成版本化离线JSON与PNG插画；客户端只读取数据。保留curriculum.json schemaVersion1并增加字段，另增activities.json schemaVersion1，稳定游戏ID为subject-type。每款游戏提供8套确定种子题组，启动时随机抽取；资源由同一目录打包至所有原生端。SVG在构建时渲染PNG，不在运行时嵌入HTML。

画板对齐网页工具箱、12色/自选色、画笔/荧光笔/橡皮、粗细、网格、历史、数字/字母底稿、作品导出。保留原1000×700稿纸坐标及旧稿完整性，避免为贴近网页4:3而拉伸已有作品；纸垫/胶带/工具布局按设备调整。底稿独立于笔迹，清空/橡皮不擦底稿；导出保留底稿但不带网格/辅助线。切换底稿清空笔迹且可撤销恢复。导出与邮箱继续经过家长验证。
