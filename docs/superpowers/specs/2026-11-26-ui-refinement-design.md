# 全端 UI 优化设计

用户已要求实施前一轮列出的全部 UI 优化，沿用网页版的绿色、奶油色、插画与原生客户端技术。

## 方案与范围

采用现有设计的渐进调整：保持六个导航入口及全部课程、60 个游戏和存档兼容。整体换肤会偏离全端按网页版实现的既定要求；仅改颜色不能解决层级与浏览密度，因此采用布局、阅读和交互共同优化。

- 首页：继续学习置于三个学科入口之前；装饰英文降为辅助层级。
- 游戏大厅：推荐、最近玩过（最多三项、本机保存）和完整题库分层；完整题库按学科与练习目标分组，搜索时不显示无关推荐与空分组。最近记录只记录打开游戏，不增加完成次数或奖励。
- 大屏：内容适当扩宽，卡片自适应列数；手机保持单列及足够触摸区域。
- 课程：核心认识和点读优先，临摹及记忆动画明确分区；宽屏弹窗适当增宽，完成/关闭可达。
- 易读与操作：增强辅助文字对比度，主要操作最小 44pt/px（Android 48dp），选中状态不只用颜色表示，按压/焦点反馈清晰，遵守减少动态效果。
- 画板：小屏工具合理换行或滚动，画纸与底稿功能保留。

## 边界

不改变课程内容、计分及旧存档；不新增依赖、账户或云端服务，不改签名/版本或自动重新提审。Mac PNG 保存问题属于另一个功能修复，本轮不宣称修复。

## 验证

网页运行现有测试和生产构建，增加最近游戏记录的异常数据/去重/上限验证；Apple 后台编译两个目标，Android 后台测试、构建及 lint。桌面 UI 自动化不运行，视觉验收采用后台浏览器可用能力；原生视觉/触控未测部分如实列出。
