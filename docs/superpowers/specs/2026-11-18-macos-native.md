# 萌呀启蒙 macOS 原生支持

在现有 Apple 原生客户端基础上增加 macOS 14+ 的 SwiftUI / AppKit 应用。复用数字 0–10、三款五关游戏、课程 JSON、中文语音、本地学习记录及家长介绍。不使用 WebView，不新增收费、账号或网络服务。

Mac 使用单窗口侧栏导航，支持窗口缩放与键盘操作。画板改用 AppKit NSView 捕获鼠标/触控板按下拖动，固定 1000×700 逻辑画纸等比显示；支持六色画笔、粗细、橡皮擦、撤销/重做/清空、草稿原子保存与恢复，窗口缩放不改变笔迹坐标。PNG 导出为 2000×1400 白底，先经过家长算术验证，再由 NSSavePanel 选择位置；取消验证或保存不写外部文件，保存失败给出可读反馈。

进度保存在 Mac 应用的本地偏好，画作使用版本化 JSON，范围校验并对坏文件安全回退。与网页、iOS、Android 不同步；大画稿限制须读写一致，不能静默丢弃旧稿。最多新增10,000笔，达到上限保留已有画作并提示。文件在独立应用目录中，支持深浅模式、可访问控件标签及鼠标快捷键。

保留现有 iOS 17 工程和 PencilKit 体验。Apple 共用界面将平台颜色/导航/输入修饰做小范围条件编译，Mac 绘画代码独立。使用现有 Xcode project 生成脚本增加 KidSproutMac、Mac 单元/UI 测试 scheme。Mac 目标将现有核心模型直接编译进入应用，避免与 iOS framework 的 SDK 混用。

交付可本机启动的 `.app` 与 zip；正式商店发布、Developer ID 签名与 Apple 公证不在此次范围。验收：Mac 构建、核心模型、画笔历史/序列化/PNG 单测、真实桌面 UI 启动和核心流程；iOS 手机/平板构建和适当回归；网页120项测试/构建/共享内容校验。
