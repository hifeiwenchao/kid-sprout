# 萌芽启蒙 · 原生应用

使用 SwiftUI / AppKit 和 Jetpack Compose 实现 Mac、iPhone/iPad 与 Android 手机/平板客户端。界面、游戏和画板由各平台原生组件运行，课程资源打包在应用内，核心学习无需联网。

## 第一阶段范围

- 认识数字 0–10、数量对应、按不同水果的实际点击数量数数、空篮子认识零。
- 数一数水果、寻找数字、比比多少，三种完整的五关游戏，答错可重试。
- 触摸画板、画笔/橡皮擦、颜色和粗细、撤销/重做/清空、草稿恢复及 PNG 分享；iOS 支持 Apple Pencil。
- 本地学习进度与游戏奖励，独立于网页存档。
- 家长区、作者介绍、邮件联系与外部操作的家长验证。

本阶段未迁移拼音、字母和其余小游戏；现有网站继续提供这些内容。共享资源已保留按 2024 新版人教教材顺序组织的拼音和英文字母，后续可以直接扩展原生课程。

```sh
npm ci
npm run native:content
npm run native:content -- --check
npm test
```

课程有变化时重新打包应用。内容不依赖 CDN 或网站在线服务，网页 Docker 构建会排除 `native/`。

## 保存、语音与分享

学习记录和画板保存在当前设备内。手机/平板卸载或清除应用数据会移除记录，Mac 移除`.app`后数据仍保留。首版不提供跨设备同步或从网页导入；Android 已关闭系统备份与设备迁移。

点读使用系统中文合成语音，音色和离线可用性取决于设备安装的语音包。没有语音时仍可用文字、图形完成所有游戏。应用不采集录音。

分享画作与联系作者需先由家长完成算术验证。移动端PNG通过系统分享面板导出，Mac通过系统保存窗口选择位置，不需要申请读取整个相册或外部存储的权限。家长验证用于避免孩子误触，不是身份认证。

## 发布边界

应用内容免费，无内购、广告、打赏、账号或后端。仓库提供开发与调试工程，尚未配置个人签名证书、App Store Connect 或安卓应用商店。iPhone/iPad 真机安装需要在 Xcode 选择开发团队；正式分发需要配置开发者账号、签名、商店截图、隐私说明与应用备案等发布资料。Android debug APK 可供测试安装，正式发布需使用自己的密钥签名。签名密钥不应提交到 Git。

后续顺序：迁移拼音与字母课程及游戏、临摹与记忆动画，再完成跨设备和商店发布验证。

本次测试环境、结果与实际验证边界见 [验证记录](VALIDATION.md)。
