# 萌芽启蒙 · Android

Kotlin / Jetpack Compose 原生应用，支持 Android 8.0（API 26）及以上的手机和平板。与网页共用构建时导出的课程、60 款游戏题库、记忆小剧场和本地 PNG 插画；运行时不执行 JavaScript、不使用 WebView。免费、离线、无账号、广告、内购和分析服务。

## 构建

需要 JDK 17 或 21、Android SDK 35。仓库提供 Gradle 8.11.1 wrapper，并固定官方分发包 SHA-256。在此目录创建被 Git 忽略的 `local.properties`：

```properties
sdk.dir=/your/path/to/android-sdk
```

```sh
./gradlew testDebugUnitTest assembleDebug lintDebug
```

首次构建需要下载 Google / Maven Central 工具和依赖。产物为 `app/build/outputs/apk/debug/app-debug.apk`，使用开发签名，可供安装测试；不是商店发布包。

`app` 的 assets 指向 `../../shared`，直接打包 `native/shared/curriculum.json`、`activities.json` 和 `illustrations/`。数据均为 schemaVersion 1。每款游戏内置 8 套确定种子题组，开局随机选择一套。更新网页纯数据或插画后，先在仓库根目录运行 `node scripts/export-native-content.mjs`。

## 学习空间

- 六个入口始终可见：探索首页、数字乐园、拼音天地、字母森林、小小画板、游戏大厅。平板宽窗口显示完整学习地图侧栏，侧栏可独立滚动；手机显示六项底部导航。家长说明和作者介绍另有入口。
- 奶油白、鼠尾草绿、浅紫、淡金配色，圆角细描边卡片，跟随系统深色外观、字体缩放与减少动画设置。记忆小剧场有限播放后停下，可重播；关闭系统动画时显示静态画面。
- 首页展示三科学习进度、第一项未学课程的直接入口、三款精选游戏和画板横幅。全部学完后进入第一课复习。成就入口展示与网页相同的八枚徽章。
- 数字 0–10 使用网页对应物体，手机为两列大卡片；详情可中英文环境下用中文点读、逐个去重数数。0 提供空篮子和放入/拿走苹果。包含 11 个记忆场景、课程临摹、逐句突出显示和点读的数字朋友歌。
- 拼音按 2024 新版人教一年级上册 14 课组织，第 9 课为 y w，包含 23 声母、24 韵母、16 整体认读音节、四声、口型、例字、拼读和规则。进度按 lesson-1 至 lesson-14 统计，完成课程由孩子或家长显式确认。例字点读为中文合成语音参考，声母轻短音请家长或老师示范。
- 字母 A–Z 分四组，手机为三列卡片；英语点读字母名和基础单词，展示大小写、中文图义、记忆场景和大小写并排临摹。
- 数字和字母课程的临摹笔迹独立于自由画板，可撤销一笔、清空重写，切课清空；不判断字形，也不累计游戏奖励。

## 游戏与声音

游戏大厅按学科、练习目标和关键词交集筛选，包含空结果与清除筛选。各科学习页按目标分组展示全部 20 个入口。

选择、依次组合、多选归类、数量装填使用真实离线题库；水果点数、数字/字母列车、胡萝卜比较、翻牌、气球、点心装填、听鼓和自由描画保留专用原生交互。翻牌三关、气球三关，描画自由练习且无奖励，其余游戏五关。答错可重试，答对锁定，下一关和末关领奖均需显式点击，每局奖励只领取一次。游戏次数与课程完成分开保存。

听鼓用本地 PCM 合成小鼓声。完整听完或展开无声圆点提示后才允许回答；播放期间禁用作答和重播。全局静音时不播放，按钮显示“开启声音”后由用户显式启用。中英文点读仅选择设备已安装且无需网络的对应语言声音，没有声音时文字、插画、圆点提示和游戏仍可使用。应用退到后台会停止声音。

## 画板与旧稿兼容

工具包含网页同款 12 色、自选 RGB 颜色、画笔、35% 透明荧光笔、橡皮、连续粗细、网格、撤销/重做、可撤销清空、37 张数字/字母底稿及前后字符切换。支持手指和触控笔。全屏按钮展开工作空间；宽屏或短窗口采用工具与稿纸左右布局，工具可独立滚动。

新稿使用 1000×700 坐标。首版 Android 的无尺寸元数据 v1 方形旧稿保留 1000×1000 显示和导出，避免拉伸已有画作。切换底稿开启 1000×700 新稿并清空笔迹，撤销可找回旧笔迹、底稿和稿纸尺寸。底稿与墨迹分层，橡皮和清空不擦底稿；导出包含底稿与墨迹，不含网格和辅助书写线。

每张画纸最多新增 10,000 笔，恢复超限旧稿会完整保留已有有效笔迹。撤销栈保留最近 100 个动作，当前画作跨重启保存，历史栈不跨重启保存。PNG 通过原生 Bitmap/Canvas 和限定 cache 路径的 FileProvider 交给系统分享，不申请存储权限。导出与邮箱跳转继续经过家长算术验证。

## 本地记录

私有 SharedPreferences `sprout-native-v1` 的版本化记录兼容首版数字、星星、最后数字和语音开关，追加 14 课拼音、26 字母及访问日期；非法值和未来版本会被过滤或安全回退。私有 `drawing-v1.json` 继续由后台串行写入和 AtomicFile 保存，新增透明度、底稿和稿纸尺寸字段，旧墨迹默认不透明。每笔及历史操作均保存并显示结果。卸载应用会移除这些记录，网页 localStorage 与原生记录独立，无跨设备同步。

没有 INTERNET、存储、相机或麦克风权限。已禁用系统备份和设备迁移。PNG 临时文件为 `cache/artwork/萌芽小画家.png`，系统可清理缓存。邮箱为 `hi@feiwenchao.com`。
