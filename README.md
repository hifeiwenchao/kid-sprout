# 萌芽启蒙

一个面向儿童、建议家长陪伴的启蒙网页，包含数字、汉语拼音与英文字母三个学习空间。低龄孩子可以先从数字和字母认知开始，拼音按入学准备情况循序渐进。使用原生 JavaScript、CSS 和 SVG 绘制，Vite 负责本地开发与打包。

## 运行

```sh
npm install
npm run dev
```

打开终端输出的本地网址。生产构建：`npm run build`；预览构建：`npm run preview`。

运行课程、题库正确性、游戏会话和进度兼容性测试：`npm test`。

## 学习地图

- 探索首页：三个学科入口、各科学习进度、继续学习与精选游戏。
- 数字乐园：1–10 数字卡片、数量对应、描画、儿歌和20个小游戏；新增零、序数、添一减一、加减、拆分、规律、凑十、平分和范围分类。
- 拼音天地：按 **2024 新版人教版一年级上册**第二至第四单元的 14 课顺序组织，第 9 课为 `y w`；包含 23 个声母、24 个韵母、16 个整体认读音节、四声及自主编写的口型与拼读示例。提供20个小游戏，覆盖声韵母分类、形近音辨认、整体认读、四声、标调、ü 拼写规则、两拼三拼及教材课次顺序。
- 字母森林：A–Z 大小写、字母名与基础单词点读；分四组展示，提供20个小游戏，覆盖大小写、字母顺序、元辅音分类、单词图义、听辨、拼词和字母计数。
- 游戏大厅：集中展示60个游戏，支持学科、练习目标和关键词组合筛选；各科页面按目标分组呈现20个入口。学科页面可通过 `#numbers`、`#pinyin`、`#alphabet` 直接访问，浏览器返回/前进可切换学习区。

拼音课次参照[统编版（2024）一年级上册目录](https://www.shimengyuan.com/jiaocais/1n2589.html)，教材修订背景参见[人民教育出版社修订说明](https://www.pep.com.cn/rjdt/rjdt/202408/t20240827_1994406.shtml)。本站为自主制作的辅助练习，口型说明、例字与游戏不使用教材原图。

拼音点读采用中文合成语音播放**例字读音参考**，不等同于标准拼音音素录音，声母的轻短音建议配合老师或家长示范。英文字母与单词显式使用英语语音；语音可用性取决于浏览器和系统安装的声音。无声时仍可使用文字、口型和游戏提示。

## Docker 运行

安装并启动 Docker（需包含 Docker Compose），在项目目录执行：

```sh
docker network create depends_proxy 2>/dev/null || true
docker compose up -d --build
```

打开 [http://localhost:8080](http://localhost:8080)。镜像使用 Node.js 22 构建页面，再由 Nginx 提供静态文件，无需在本机安装 Node.js。

如需更换端口，例如使用 `3000`：

```sh
KID_SPROUT_PORT=3000 docker compose up -d --build
```

查看日志与停止服务：

```sh
docker compose logs -f
docker compose down
```

修改源码后，重新执行启动命令即可构建并更新容器。学习记录仍保存在浏览器中；更换访问地址或端口会使用独立的浏览器存储。

项目服务同时加入 `depends_proxy` Docker 网络，供外部 Nginx 容器通过 `kid-sprout-web:80` 代理访问。使用项目自带的 [deploy/nginx/kid-sprout.conf](deploy/nginx/kid-sprout.conf) 时，将配置复制到 Nginx 的 `conf.d` 目录并重载 Nginx。

也可以直接使用 Docker：

```sh
docker build -t kid-sprout:local .
docker run -d --name kid-sprout -p 8080:80 kid-sprout:local
```

## 功能

新游戏采用选择、依次组合、多选归类、数量装填四种玩法，每次5关；答错可以重试，通关后累计奖励，不把游戏次数误记为课程完成。原有描画、翻牌、气球等玩法继续保留。

- 1–10 数字卡片：中文点读、数量对应、逐个点击数数。
- 水果数数、数字捉迷藏：随机出题，每次 5 关，鼓励反馈与通关奖励。
- 数字描画：支持鼠标与触屏，切换数字、清空重画。
- 数字小火车：补齐连续数字里的空车厢，5 关练习数字顺序。
- 小兔分胡萝卜：比较两篮实际数量，选择更多的一篮，5 关趣味挑战。
- 记忆翻翻乐：数字与相同数量的星星配对，3 关从小数字逐步过渡到 10。
- 数字气球派对：按数字顺序点气球，3 关依次练习 1–5、6–10 和 1–10。
- 小熊点心铺：按照小熊的订单装饼干，支持放入与取出，5 关练习数字对应数量。
- 小耳朵听听：听真实合成的小鼓声并数一数，5 关练习 1–5；可重复播放或展开圆点提示，无声环境也能玩。
- 数字儿歌：按句播放，突出显示当前歌词。
- 数字学习进度、成就与打卡记录保存在当前浏览器的 localStorage（`number-garden`），保留旧版记录；拼音课次和字母进度另存于 `sprout-learning`。
- 桌面、平板、手机自适应；键盘可操作，支持减少动态效果偏好。

点读由浏览器 Web Speech API 提供。主要插画使用本地 SVG，字母与拼音装饰由 CSS 绘制；字体包含系统回退。无账号、无后端服务。
